# What is Sentry?

Sentry ek error monitoring tool hai jo tumhari application mein hone wale errors aur performance issues ko track karta hai. Isse production mein pata chalta hai ki application mein kya problem aayi, kahan aayi aur kyun aayi. Matlab, users ko error mile aur tumhe uske baare mein pata hi na chale, is problem ka solution. 😄

Sentry ke main features hain:

- Error Tracking: Runtime errors ko capture karta hai.
- Stack Trace: Batata hai ki error kis file aur line par aaya.
- Performance Monitoring: Slow API requests aur database operations identify karne mein help karta hai.
- Alerts: Naye ya important errors aane par notification bhej sakta hai.
- Issue Grouping: Ek hi tarah ke multiple errors ko ek issue mein group karta hai.
