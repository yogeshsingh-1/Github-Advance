# Prometheus data collect aur store karta hai, jabki Grafana us data ko graphs aur dashboards mein dikhata hai. Dono monitoring mein kaam aate hain, lekin dono ka role alag hai.

# Prometheus

Data collection

- Metrics collect karta hai.
- Time-series data store karta hai.
- PromQL se queries run karta hai.
- Metrics ke basis par alerts trigger kar sakta hai.

# Grafana

Visualization

- Graphs aur dashboards banata hai.
- Prometheus se data read karta hai.
- Metrics ko visually compare karta hai.
- Dashboard-based alerts configure kar sakte ho.
