# What is APM? 
APM is a Application Performance Monitoring. 

APM ka full form hai Application Performance Monitoring. Iska use production mein running application ki performance monitor karne, slow APIs identify karne aur errors ka root cause find karne ke liye hota hai.

Simple example: Tumhari Node.js API /api/users ko response dene mein 5 seconds lag rahe hain. APM tumhe investigate karne mein help karta hai ki problem database query mein hai, external API mein ya Node.js code mein.
