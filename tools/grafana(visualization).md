# What is grafana ?

Grafana ek monitoring aur visualization tool hai jo tumhare server, Node.js application aur database ke metrics ko graphs aur dashboards mein dikhata hai.

Simple example: Prometheus tumhare backend ka CPU usage 75% collect karta hai, aur Grafana us data ko graph mein dikhata hai, taaki tum easily samajh sako ki server par load kab badh raha hai. Insaan numbers se zyada graphs samajhta hai, isliye ye tool kaafi useful hai.

# Grafana dashboard mein tum dekh sakte ho:

- CPU usage kitna hai.
- RAM kitni use ho rahi hai.
- API response time kitna hai.
- Kitni requests aa rahi hain.
- Errors kab badh rahe hain.
