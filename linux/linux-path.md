| Command   | Kya batata hai?                                                               | Kab use hota hai?                         |
| --------- | ----------------------------------------------------------------------------- | ----------------------------------------- |
| `which`   | Kaunsi executable run hogi                                                    | PATH debugging, version conflicts         |
| `whereis` | Software ki binary, library, man pages                                        | Installation location dekhne ke liye      |
| `type`    | Shell command ko kaise treat karta hai (builtin, alias, function, executable) | Command ki actual nature samajhne ke liye |
