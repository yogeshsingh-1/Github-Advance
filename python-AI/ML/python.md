# Python Collections

Python provides four built-in collection data types for storing multiple values:

1. **List**
2. **Tuple**
3. **Set**
4. **Dictionary**

Each collection has different properties and use cases.

---

# Python List

A **List** is used to store multiple items in a single variable.

A Python list is similar to an array, but unlike arrays in some other languages, a Python list can store values of **different data types**.

### Example

```python
mylist = ["apple", "banana", "cherry"]
