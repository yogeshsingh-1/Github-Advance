# What is an API?

API stands for **Application Programming Interface**.

An API is an interface that allows different applications or software components to communicate with each other.

In a web application, an API is commonly used as a communication interface between the frontend and backend.

OR 
API is a bridge b/w client and server applications.

For example:

Frontend → API Request → Backend
Frontend ← API Response ← Backend
