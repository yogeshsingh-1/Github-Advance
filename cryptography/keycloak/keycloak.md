# What is Keycloak?

Keycloak ek open-source Identity and Access Management (IAM) tool hai jo tumhari application mein login, authentication, Single Sign-On (SSO), aur role-based access control manage karta hai.

- Provide authentication(401) to applications
- Deals with storing and authenticating users
- User federation
- Storing authentication
- User Management
- Fine grained authorization

Identity Provider (IdP)

# Feature

1. Single Sign On
   Users have to autheticate against keycloak rather than individual applications.

Login once against keycloak & access apps seamlessly.

Single Logout of support.

2. Identity Brokering & Social Login

Capability to login via social network providers.
Identity Provider (IdP) (Facebook, Instagram , Google)

Standard Protocols Support
(OpenId Connect, OAuth 2.0 & SAML)

3. User Federation 

Support for LDAP and Active directory servers.
Capabiltiy to connect custom user stores. 

4. Admin Console

Enable admins to manage the keycloak server.

5. Account management console

# Keycloak kya karta hai?(Feature)

1. Authentication

User ki identity verify karta hai, jaise username-password ya supported external identity provider ke through login.

2. Single Sign-On (SSO)

User ek baar login kare, phir multiple connected applications access kar sake bina har application mein dobara login kiye.

3. Token management

OIDC/OAuth 2.0 protocols ke through access tokens aur ID tokens issue kar sakta hai.

4. Authorization

Roles aur permissions manage kar sakta hai, jaise admin, manager, aur user.
