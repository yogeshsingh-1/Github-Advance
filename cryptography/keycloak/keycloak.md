# What is Keycloak?

Keycloak ek open-source Identity and Access Management (IAM) tool hai jo tumhari application mein login, authentication, Single Sign-On (SSO), aur role-based access control manage karta hai.

# Keycloak kya karta hai?

1. Authentication

User ki identity verify karta hai, jaise username-password ya supported external identity provider ke through login.

2. Single Sign-On (SSO)

User ek baar login kare, phir multiple connected applications access kar sake bina har application mein dobara login kiye.

3. Token management

OIDC/OAuth 2.0 protocols ke through access tokens aur ID tokens issue kar sakta hai.

4. Authorization

Roles aur permissions manage kar sakta hai, jaise admin, manager, aur user.
