<!-- What is Hashing -->

Hashing is the process of converting any binary input (like string ,file or data) into a fixed size output of bytes using a mathematical function called a Hashing Function.

This output is typically represented as a string of hexadecimal characters, but fundamentally, the size is in bytes.

# Characterstics of Hashing Functions:
1. Same input always gives the same output.
2. The hash function should return the hash value quickly.
3. Irreversible ->  It should not be feasible to reverse the hash to get the original input.
4. Collision-resistant -> Two diffrent inpputs should not produce the same output.
5. Small change in input produce a significantly diffrent output.
