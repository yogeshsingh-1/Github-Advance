# What is OAUATH ? -> 403

OAuth is an authorization(403) mechanism that allows an application to access a user's resources( like files, photos or email) without sharing the user's password.

OAUTH is an open standard for access delegation. It allows a third-party application to access a user's resources (like files, photos, or emails) without exposing their credentials (like username or password).
 
OAuth (Open Authorization) ek standard hai jisse ek application ko dusri application ke resources access karne ki permission milti hai, bina user ka password share kiye.

OAuth ka main purpose hai: password share kiye bina kisi app ko limited access dena.

- OAuth = "Password diye bina permission dena"
