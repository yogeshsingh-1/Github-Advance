# What is OAUATH ? -> 403

OAuth is an authorization mechanism that allows an application to access a user's resources without sharing the user's password.

OAuth (Open Authorization) ek standard hai jisse ek application ko dusri application ke resources access karne ki permission milti hai, bina user ka password share kiye.

OAuth ka main purpose hai: password share kiye bina kisi app ko limited access dena.

- OAuth = "Password diye bina permission dena"

Ex :-
Tum
↓
Google
↓
"Is app ko tumhari Drive access karne dein?"
↓
Tum → YES
↓
Google → App ko Access Token deta hai
↓
App → Token dikha kar Drive access karti hai

# What is OAUTH2.0 ?

OAuth 2.0 is an authorization framework that allows an application to access a user's resources without sharing the user's password.

OAuth = concept → password share kiye bina access dena
OAuth 2.0 = us concept ko implement karne ka modern framework/standard
