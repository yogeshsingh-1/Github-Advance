# what is vpc?

VPC is virtual private cloud.

VPC (Virtual Private Cloud) AWS ke andar tumhara apna private virtual network hota hai.

VPC stands for Virtual Private Cloud. It is a logically isolated virtual network in AWS where we can launch resources such as EC2 instances and databases. It allows us to configure IP ranges, subnets, routing, and network security to control communication between resources and the internet.

VPC (Virtual Private Cloud) ek aisa private network hai jisme tum apne AWS resources, jaise EC2 servers, databases aur load balancers, ko securely deploy aur manage kar sakte ho.

# Parts of IP address?

An IP address is split into two distinct parts: the Network ID and the Host ID.

# What is subnet?

Ek bade network ko choote choote part mai divide karna subnetting hai.

A subnet (short for subnetwork) is a smaller, logical subdivision of a larger IP network.
