aws -> Amazon Web Service
AMI -> Amazon Machine Image  -> An **AMI (Amazon Machine Image)** is a pre-configured operating system image.
EC2 -> Elastic Compute Cloud
S3 -> Simple Storage Service(Amazon S3)
VPC -> Virtual Private Cloud
ECS -> Elastic Container Service
EKS -> Elastic Kubernetes Service
IAM -> Identity and Access Management

AWS has 200+ services, but most backend developers use a much smaller set regularly. Focus on the core services first.

The full forms of ECS and EKS are Amazon Elastic Container Service and Amazon Elastic Kubernetes Service, respectively. Both are powerful container orchestration tools provided by Amazon Web Services (AWS) to deploy, manage, and scale containerized applications.
