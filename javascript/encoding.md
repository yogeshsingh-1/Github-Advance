# Common types of encoding

1. encodeURIComponent(url_string);
   URL mein spaces aur special characters ko safely represent karne ke liye.

2. decodeURIComponent(url_String)
   URL mein spaces aur special characters ko remove karne ke liye.

3. atob()
   base64 url ko string mai change karta hai.
   Base64-encoded string ko decode karta hai.

4. btoa()
   Normal binary-compatible string ko Base64 mein encode karta hai.
